# Краткая справка по проекту WTIS

**Документ:** `PROJECT_DOCUMENTATION.md`  
**Проект:** **WTIS** (Web-based Technical Image System) — веб-приложение для обработки, анализа и визуализации научных и технических изображений.

---

## 📌 Основное назначение
Приложение предоставляет инструменты для:
- Загрузки и отображения изображений (PNG, JPG, JPEG, TPT)
- Редактирования (кисть, ластик, фигуры, текст)
- Научной обработки матричных данных
- Полиномиальной аппроксимации поверхностей
- Применения фильтров (медианный, Собеля, пороговый и др.)
- Цветового картирования (colormaps: hot, jet, gray, viridis, plasma)
- Выделения областей (прямоугольник, лассо)
- Сохранения результатов (локально, на сервер, в MinIO)

---

## 🏗️ Архитектура
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Plotly.js
- **Backend:** Python 3.x + Flask
- **Хранение:** LocalStorage, файловая система, MinIO (S3-совместимое объектное хранилище)
- **Паттерны:** Observer Pattern, Single Source of Truth, Separation of Concerns

## ⚙️ Запуск
```bash
pip install flask minio werkzeug
export MINIO_ENDPOINT='127.0.0.1:9000'
python app.py
# Сервер запускается на http://localhost:15404
```

---

## 📡 API Endpoints
- `/images`, `/upload`, `/delete/<filename>` — работа с изображениями
- `/list_minio`, `/upload_minio`, `/download_minio/<object>` — работа с MinIO
- `/workflow`, `/viewIcons`, `/new_int` — дополнительные страницы

---

## 📦 JavaScript модули
1. **math-utils.js** — полиномиальная аппроксимация, медианный фильтр, colormaps
2. **canvas-utils.js** — рисование (Брезенхем, Лянга-Барски), маски, заливка
3. **file-utils.js** — сохранение в TPT, конвертация форматов
4. **file-manager.js** — история (undo/redo), recent files

## 🐛 Частые проблемы
- Ошибка подключения к MinIO → проверить сервер и credentials
- Ошибка 413 → увеличить `MAX_CONTENT_LENGTH`
- Модули не импортируются → добавить `type="module"` в script
- Canvas пустой → проверить консоль браузера и размеры
